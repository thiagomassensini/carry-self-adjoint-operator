# Reflection, parity, and the signed height operator

## What the source files add

The five source files fit the existing operator chain at different layers.
Their useful content is not a new target spectrum, but a repeated relation:
an exact reflection splits a state into two orthogonal sectors, and the
operator either preserves or exchanges those sectors according to its parity.

The two-variable Green-gamma note supplies the abstract pattern.  After
kernel factorization, reflection acts by

```text
R gamma(z) = gamma(-z),   R^2 = I,   R* = R.
```

The Jacobi notes and the laboratories supply the finite operator pattern.
The defect jets are generated by one Jacobi section,

```text
x_j = J_N^j x_0,
X_N = [x_0 ... x_(N-1)],
G_N = X_N* X_N,
K_N = X_N* J_N X_N,
```

and whitening gives the positive height operator

```text
T_N = J_N^(-1/2).
```

The projective identity belongs to the Jacobi layer:

```text
J_N = P_N J_(N+1) P_N*.
```

It must not be silently transferred to `T_N`; inverse square root does not in
general commute with compression.

## The residue reflection already present in the geometry

For one camera with cyclic channel set `ZMod d`, define pullback by

```text
(R_res f)(a) = f(-a).
```

The exact geometry proves

```text
R_res^2 = I,
<R_res f, R_res g> = <f,g>,
R_res* = R_res.
```

Therefore

```text
P_even = (I + R_res)/2,
P_odd  = (I - R_res)/2
```

are complementary orthogonal projections.  The literal centered bracket and
oriented leg signals are

```text
b_r = delta_r + delta_(-r) - 2 delta_0,
ell_r = delta_r - delta_(-r).
```

Consequently

```text
R_res b_r =  b_r,     P_odd b_r = 0,
R_res ell_r = -ell_r, P_even ell_r = 0.
```

At an antipodal radius, the two leg channels coincide and `ell_r = 0`.  Thus
the one-channel orbit is exactly the degeneration of the odd direction, not
an exceptional convention.

These statements are now formalized in
`BracketResidueReflectionOperator.lean`.

## The parity of the signed height realization

Starting from the internally generated positive operator `T_N`, define

```text
H_N = [ T_N   0  ]
      [  0  -T_N ].
```

There are two different involutions on this doubled space:

```text
S = [0 I]       Gamma = [I  0]
    [I 0],              [0 -I].
```

They have different jobs:

| involution | exact relation | meaning |
|---|---|---|
| sector swap `S` | `S H_N S = -H_N` | exchanges positive and negative heights |
| grading `Gamma` | `Gamma H_N = H_N Gamma` | labels the two signed sectors |

Both square to the identity and are symmetric.  In particular, `S` is the
parity operator for signed height; `Gamma` is not.  The characteristic
polynomial factors exactly as

```text
charpoly(H_N) = charpoly(T_N) charpoly(-T_N).
```

These statements are now formalized in `SignedFiniteHeightOperator.lean`.

## What is proved and what remains the bridge

The residue reflection `R_res`, the reflected Green-state involution, and the
signed-sector swap `S` have the same abstract signature: symmetric
involutions with an even/odd decomposition.  They do not yet have the same
type, so similarity of formulas is not an identification.

The next canonical object is a concrete bounded readout/intertwiner `B` from
the completed Green/camera state into the height realization satisfying an
equation of the form

```text
B R_res = S B
```

together with preservation of the Green kernel, the logarithmic jets, and the
completion channel.  Only after constructing such a `B` can residue parity
be transported into signed-height parity.  The source notes identify this as
the missing state-readout problem; the present formalization isolates both
sides of that equation without assuming the bridge.

The resulting exact chain is therefore

```text
center/legs
  -> cyclic reflection
  -> orthogonal even/odd residue sectors
  -> Green defect jets
  -> Hankel pair
  -> Jacobi section J_N
  -> positive height T_N
  -> signed height H_N
```

The construction uses only the internal geometry, completed cutoff identity,
Green relations, moment jets, and finite functional calculus.  No list of
heights is supplied anywhere in the chain.
